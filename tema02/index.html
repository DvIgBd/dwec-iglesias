¿Por qué casi todos los navegadores comparten motor?

Crear y mantener un motor de renderizado es carísimo: tiene que interpretar HTML, CSS y JavaScript cumpliendo miles de especificaciones que no paran de cambiar. Por eso la mayoría de empresas prefieren partir de Chromium, el proyecto de código abierto de Google, y construir su navegador encima. Así, Chrome, Edge y Opera comparten el motor Blink y el motor de JavaScript V8. Los únicos grandes que se quedan fuera son Firefox, con Gecko, y Safari, con WebKit. Para quien desarrolla una web, esto tiene una parte buena y una mala. La buena es que, si funciona en Chrome, probablemente funcione en casi todos los demás. La mala es que eso no basta: Firefox y Safari pueden comportarse de forma distinta, y además tanta dependencia de un solo motor hace que Google tenga mucho poder sobre cómo evoluciona la web.
